# 1. 阿克曼转向到底要解决什么问题

汽车在低速转弯时，如果把四个车轮都看成“纯滚动、不侧滑”，那么每个车轮在地面上的速度方向都必须与车轮平面一致。

这句话非常关键。

因为轮胎不能横着滑，所以：

* 车轮指向哪边
* 轮心瞬时速度就必须朝哪边

如果前轮左右两个轮子的转角相同，那么它们延长线通常不会交于同一点，于是车辆刚体运动与“纯滚动约束”会互相矛盾，轮胎就会产生侧滑。

**阿克曼转向几何**就是为了解决这个矛盾：
让左右前轮转角不同，使所有车轮的轮轴法线（或者说各轮速度方向对应的瞬时转动关系）都指向同一个瞬时转动中心。

这个共同点，叫：

* **瞬时转动中心**
* Instantaneous Center of Rotation, **ICR**

---

# 2. 理想阿克曼模型的核心几何思想

先看一辆四轮车，假设：

* 后轮不转向
* 前轮负责转向
* 车体是刚体
* 四个车轮都纯滚动、无侧偏角
* 地面是平面

设车辆左转。

这时：

* 车辆所有点都绕某个地面上的点 $O$ 做瞬时圆周运动
* 这个点 $O$ 位于车辆左侧某处
* 每个轮心的速度方向都与“轮心到 $O$ 的连线”垂直

所以每个车轮的朝向必须满足：

> 车轮平面方向与该轮心的瞬时速度方向一致

等价地说：

> 车轮平面的法线必须穿过同一个 ICR

这就是阿克曼几何条件。

---

# 3. 车辆几何参数定义

我们先定义最常用的几何量。

设：

* 轴距：$L$
  前后轴中心之间的距离

* 轮距：$W$
  左右轮中心之间的距离（通常指前轮轮距，理想模型里常也近似等于后轮轮距）

* 左前轮转角：$\delta_l$

* 右前轮转角：$\delta_r$

假设车辆左转，则：

* 左前轮是**内侧轮**
* 右前轮是**外侧轮**

所以左转时通常有：

$$
\delta_l > \delta_r
$$

因为内侧轮转弯半径更小，必须打更大的角度。

---

# 4. 为什么左右轮角必须不同

## 4.1 后轴中心作为参考

设后轴中心点为 $R$，车辆左转时，ICR 位于后轴延长线左侧一点 $O$。

令：

$$
R = \text{后轴中心到 ICR 的距离}
$$

这个 $R$ 常被称为：

* 车辆参考点转弯半径
* 通常是后轴中心轨迹半径

则：

* 左后轮半径：$R - \frac{W}{2}$
* 右后轮半径：$R + \frac{W}{2}$

前轮由于比后轮前移了一个轴距 $L$，所以：

* 左前轮轮心到 ICR 的位置形成直角三角形
* 右前轮轮心到 ICR 的位置也形成直角三角形

于是前轮方向必须分别沿各自圆轨迹的切线方向。

---

## 4.2 从三角形直接写出转角

对于左前轮（内侧轮）：

* 横向距离：$R - \frac{W}{2}$
* 纵向距离：$L$

于是有：

$$
\tan \delta_l = \frac{L}{R - \frac{W}{2}}
$$

对于右前轮（外侧轮）：

$$
\tan \delta_r = \frac{L}{R + \frac{W}{2}}
$$

这就是**理想阿克曼转向几何的基本公式**。

---

# 5. 阿克曼经典形式的推导

上面是正切形式。很多时候还会写成余切形式，因为更简洁。

由

[
\tan \delta_l = \frac{L}{R - \frac{W}{2}}
]

可得

[
\cot \delta_l = \frac{R - \frac{W}{2}}{L}
]

同理

[
\cot \delta_r = \frac{R + \frac{W}{2}}{L}
]

两式相减：

[
\cot \delta_r - \cot \delta_l
= \frac{R + \frac{W}{2}}{L} - \frac{R - \frac{W}{2}}{L}
]

[
\cot \delta_r - \cot \delta_l
= \frac{W}{L}
]

这就是最经典的**阿克曼转向约束**：

[
\boxed{\cot \delta_r - \cot \delta_l = \frac{W}{L}}
]

它的意义非常深：

* 左右轮角不是独立的
* 只要满足这个关系，左右前轮的法线就交于后轴线上同一个点
* 于是四轮纯滚动条件成立

---

# 6. 用几何再解释一次这个公式为什么成立

你可以把左右前轮各自看成一条线：

* 线的方向 = 车轮平面方向
* 线的法线方向 = 该轮与 ICR 的连线方向

要让两个前轮都绕同一个 ICR 转，就要求：

* 左前轮法线过 ICR
* 右前轮法线也过 ICR

因为两个轮心左右相距 (W)，前后相对后轴相距 (L)，所以最终几何关系就固定成：

[
\cot \delta_r - \cot \delta_l = \frac{W}{L}
]

本质上，这是一个“**同一交点条件**”。

---

# 7. 理想单轨模型和阿克曼模型的关系

在控制和机器人里，更常见的是**单轨模型**（bicycle model，自行车模型）。

它把：

* 左右前轮合并成一个虚拟前轮
* 左右后轮合并成一个虚拟后轮

于是车只剩两条轮迹，模型大大简化。

## 7.1 为什么能合并

因为在低速、理想滚动条件下，左右轮虽然角度不同，但它们都对应同一个 ICR，所以我们可以定义一个“等效前轮转角” (\delta)，使整个车的质心或后轴中心的运动能被一个单前轮近似描述。

这个 (\delta) 不是简单平均，但在理想模型中常定义为满足：

[
\tan \delta = \frac{L}{R}
]

也就是：

[
R = \frac{L}{\tan \delta}
]

这就是单轨模型的核心关系。

---

## 7.2 它和左右轮角如何联系

前面阿克曼模型有：

[
\tan \delta_l = \frac{L}{R - \frac{W}{2}}, \qquad
\tan \delta_r = \frac{L}{R + \frac{W}{2}}
]

而单轨模型定义：

[
\tan \delta = \frac{L}{R}
]

所以：

[
\delta_l = \arctan\left(\frac{L}{R - \frac{W}{2}}\right)
]

[
\delta_r = \arctan\left(\frac{L}{R + \frac{W}{2}}\right)
]

如果已知等效转角 (\delta)，先算

[
R = \frac{L}{\tan \delta}
]

再代回去即可得到左右前轮角。

这在实际控制中很常见：

* 上层控制器输出一个等效转角 (\delta)
* 转向机构根据阿克曼几何分配成 (\delta_l,\delta_r)

---

# 8. 理想阿克曼模型的运动学推导

下面开始推导车辆的运动学方程。

---

## 8.1 车辆状态变量

取车辆后轴中心为参考点，定义状态：

[
x, y
]

表示后轴中心在全局坐标系中的位置；

[
\psi
]

表示车身航向角，即车体纵向轴相对于全局 (x) 轴的夹角；

[
v
]

表示后轴中心沿车体纵向的速度；

[
\delta
]

表示单轨等效前轮转角。

---

## 8.2 位置运动方程

因为车辆沿车体朝向前进，所以后轴中心速度在世界坐标系中分解为：

[
\dot{x} = v\cos\psi
]

[
\dot{y} = v\sin\psi
]

这个很好理解：速度大小是 (v)，方向是 (\psi)。

---

## 8.3 航向角速度的推导

这是最关键一步。

根据单轨等效几何：

[
\tan\delta = \frac{L}{R}
]

所以

[
R = \frac{L}{\tan\delta}
]

而绕 ICR 运动时，角速度满足：

[
\dot{\psi} = \frac{v}{R}
]

代入 (R)：

[
\dot{\psi} = \frac{v}{L/\tan\delta}
]

[
\boxed{\dot{\psi} = \frac{v}{L}\tan\delta}
]

这就是理想阿克曼/单轨运动学模型中最核心的式子。

---

## 8.4 完整运动学模型

于是理想阿克曼单轨运动学模型为：

[
\boxed{
\begin{aligned}
\dot{x} &= v\cos\psi \
\dot{y} &= v\sin\psi \
\dot{\psi} &= \frac{v}{L}\tan\delta
\end{aligned}}
]

如果把速度 (v) 和转角 (\delta) 看成输入，那么这就是最常见的控制系统形式。

---

# 9. 航向角速度公式再详细推导一次

你如果想真正理解这一步，我再从“圆周运动”角度细拆一遍。

设车辆后轴中心绕 ICR 做圆周运动，半径为 (R)。

圆周运动的基本关系：

[
v = \omega R
]

其中：

* (v)：切向速度
* (\omega)：角速度
* (R)：半径

这里车辆的角速度就是航向角变化率：

[
\omega = \dot{\psi}
]

所以：

[
\dot{\psi} = \frac{v}{R}
]

又因为阿克曼/单轨几何有：

[
\tan \delta = \frac{L}{R}
]

所以：

[
R = \frac{L}{\tan\delta}
]

代入得：

[
\dot{\psi} = \frac{v}{L/\tan\delta}
= \frac{v}{L}\tan\delta
]

推导结束。

---

# 10. 曲率形式的表达

在路径跟踪中，常常更喜欢用**曲率** (\kappa)。

曲率定义为：

[
\kappa = \frac{1}{R}
]

而根据上面关系：

[
R = \frac{L}{\tan\delta}
]

所以：

[
\kappa = \frac{\tan\delta}{L}
]

于是航向角速度也可以写成：

[
\dot{\psi} = v\kappa
]

这很重要，因为它表明：

* 速度决定沿路径走多快
* 曲率决定路径弯得多厉害

因此理想阿克曼车辆本质上是一个**曲率受控系统**。

---

# 11. 小转角近似

当转角很小时，

[
\tan\delta \approx \delta
]

于是：

[
\dot{\psi} \approx \frac{v}{L}\delta
]

[
\kappa \approx \frac{\delta}{L}
]

这在很多线性控制推导中非常常见。

但注意：

* 这只适用于小角度
* 大转角掉头、低速急转时误差会明显增大

---

# 12. 从左右前轮到等效前轮的严格关系

很多人会问：单轨模型里的 (\delta) 到底是不是 ((\delta_l+\delta_r)/2)？

严格来说，**不是定义上的必须平均值**。

因为真实几何里：

[
\tan\delta_l = \frac{L}{R - W/2}, \qquad
\tan\delta_r = \frac{L}{R + W/2}
]

而等效前轮角 (\delta) 是通过“后轴中心半径 (R)”定义出来的：

[
\tan\delta = \frac{L}{R}
]

所以 (\delta) 的本质是“与参考轨迹半径对应的虚拟前轮角”。

在轮距相对半径较小的时候，才可以近似认为：

[
\delta \approx \frac{\delta_l+\delta_r}{2}
]

但这不是严格恒等式。

---

# 13. 理想阿克曼模型的无侧滑约束

这个模型的数学基础，其实是**非完整约束**。

以后轴中心为参考点，理想情况下车辆横向速度为 0，也就是：

在车体坐标系里，

* 纵向速度可非零
* 横向速度必须为 0

写到世界坐标系里，就是：

[
-\dot{x}\sin\psi + \dot{y}\cos\psi = 0
]

这个式子的含义是：

> 车辆不能沿自身横向平移

这就是理想轮式车辆最基本的非完整约束。

因为它约束的是速度，而不是位置，所以它不能积分成一个纯位置约束，这就是“非完整”的含义。

---

# 14. 为什么阿克曼车是非完整系统

从自由度看：

平面刚体有 3 个位姿自由度：

[
x,\ y,\ \psi
]

但由于纯滚动约束，车辆不能横移，所以瞬时可行动作只有：

* 前进/后退
* 改变转角后前进引起航向变化

因此它不能像全向车那样直接往侧面走。

这就是阿克曼车控制比全向底盘更困难的根本原因。

---

# 15. 理想模型下各轮速度关系

既然整车绕 ICR 转动，不同轮心到 ICR 的半径不同，所以各轮线速度也不同。

若整车角速度为 (\omega)，则任意轮心速度大小为：

[
v_i = \omega r_i
]

例如：

* 左后轮半径：(r_{rl} = R - \frac{W}{2})
* 右后轮半径：(r_{rr} = R + \frac{W}{2})

则：

[
v_{rl} = \omega\left(R - \frac{W}{2}\right)
]

[
v_{rr} = \omega\left(R + \frac{W}{2}\right)
]

所以转弯时：

* 外侧轮速度更大
* 内侧轮速度更小

这也是差速器存在的重要原因之一。否则后轮左右等速驱动会产生打滑。

---

# 16. 理想阿克曼模型的控制输入形式

常见有三种。

## 16.1 以速度和转角为输入

[
u = [v,\ \delta]^T
]

模型：

[
\dot{x}=v\cos\psi,\quad
\dot{y}=v\sin\psi,\quad
\dot{\psi}=\frac{v}{L}\tan\delta
]

这是最常见形式。

---

## 16.2 以速度和曲率为输入

[
u = [v,\ \kappa]^T
]

模型：

[
\dot{x}=v\cos\psi,\quad
\dot{y}=v\sin\psi,\quad
\dot{\psi}=v\kappa
]

其中：

[
\kappa = \frac{\tan\delta}{L}
]

这种形式特别适合路径跟踪。

---

## 16.3 加上转角动态

真实转向系统不可能瞬间从一个角度跳到另一个角度，所以常加入转角动态：

[
\dot{\delta} = u_\delta
]

或者一阶系统：

[
\dot{\delta} = -\frac{1}{\tau}\delta + \frac{1}{\tau}\delta_{cmd}
]

于是状态变成：

[
[x,y,\psi,\delta]^T
]

这比纯运动学模型更接近实际。

---

# 17. 理想阿克曼和真实车辆的差别

到这里你会发现，这个模型很漂亮，但它是“理想的”。现实中会偏离很多。

---

## 17.1 真实轮胎会有侧偏角

高速转弯时，轮胎受力后会弹性变形，车轮指向与真实速度方向不再完全一致，出现：

* 前轮侧偏角
* 后轮侧偏角

于是“纯滚动无侧滑”不再成立。

这时就不能只用理想阿克曼运动学模型，而要用：

* 动力学自行车模型
* 轮胎线性侧偏模型
* Pacejka 等轮胎模型

---

## 17.2 转向机构未必完全满足理想阿克曼几何

机械连杆设计通常只在某个工况附近近似满足阿克曼条件：

* 低速小半径可能接近理想
* 高速时很多车反而故意设计成不完全阿克曼，甚至趋向平行转向，以改善轮胎受力和操控

所以“阿克曼几何”更多是低速几何约束的理想目标。

---

## 17.3 车身参考点不同，公式会变化

如果你选的参考点不是后轴中心，而是：

* 质心
* 前轴中心
* 车辆某个安装点

则：

[
\dot{x},\dot{y}
]

和角速度关系的写法会有所不同。

但本质不变：整车仍绕 ICR 做瞬时转动。

---

# 18. 用质心作为参考点时的模型

如果车辆质心位于后轴前方距离 (l_r)，前轴后方距离 (l_f)，则：

[
L=l_f+l_r
]

理想单轨模型有时写成：

[
\dot{x} = v\cos(\psi+\beta)
]
[
\dot{y} = v\sin(\psi+\beta)
]
[
\dot{\psi} = \frac{v}{l_r}\sin\beta
]

其中

[
\beta = \arctan\left(\frac{l_r}{L}\tan\delta\right)
]

这里的 (\beta) 是质心速度方向与车身轴线的夹角。

注意：

* 这并不是轮胎侧偏角
* 它只是因为参考点从后轴中心换成了质心而引入的几何偏差角

后轴中心模型更直观，质心模型更适合某些控制推导。

---

# 19. 理想阿克曼模型最本质的三层结构

可以把它理解成三层。

## 第一层：轮胎纯滚动约束

每个车轮不能横向滑动。

## 第二层：共同 ICR 条件

所有车轮必须对应同一个瞬时转动中心。

## 第三层：单轨等效

把左右轮折叠成一个等效前轮，得到

[
\dot{\psi}=\frac{v}{L}\tan\delta
]

所以整个模型不是凭空来的，而是从轮胎无侧滑几何一步一步推出来的。

---

# 20. 一个完整的推导链条总结

我把最关键的推导链条浓缩成一条线：

### 第一步：纯滚动

轮心速度方向必须与车轮平面一致。

### 第二步：刚体平面运动

任意刚体的瞬时平面运动都等价于绕某个 ICR 转动。

### 第三步：所有车轮共享同一 ICR

所以每个车轮朝向必须与该 ICR 对应的圆轨迹切线一致。

### 第四步：得到左右前轮关系

[
\tan \delta_l = \frac{L}{R-\frac{W}{2}},\qquad
\tan \delta_r = \frac{L}{R+\frac{W}{2}}
]

### 第五步：化成经典阿克曼公式

[
\cot\delta_r-\cot\delta_l=\frac{W}{L}
]

### 第六步：定义等效前轮角

[
\tan\delta = \frac{L}{R}
]

### 第七步：由圆周运动得到航向变化率

[
\dot{\psi} = \frac{v}{R} = \frac{v}{L}\tan\delta
]

### 第八步：得到理想阿克曼单轨运动学模型

[
\dot{x}=v\cos\psi,\quad
\dot{y}=v\sin\psi,\quad
\dot{\psi}=\frac{v}{L}\tan\delta
]

---

# 21. 这个模型适用于什么场景

它非常适合：

* 低速移动机器人
* 自动驾驶低速路径规划
* 泊车控制
* 轨迹跟踪基础建模
* MPC/LQR 的低速运动学层

它不太适合直接描述：

* 高速极限操稳
* 轮胎打滑明显
* 冰雪湿滑地面
* 强加减速耦合的极限工况

这些场景需要动力学模型。

---

# 22. 一个直觉例子

设：

* (L=2.8\text{ m})
* (W=1.6\text{ m})
* 等效转角 (\delta=10^\circ)

则：

[
R = \frac{L}{\tan 10^\circ}
\approx \frac{2.8}{0.1763}
\approx 15.88\text{ m}
]

内外前轮角分别为：

[
\delta_l=\arctan\left(\frac{2.8}{15.88-0.8}\right)
\approx \arctan(0.1857)
\approx 10.53^\circ
]

[
\delta_r=\arctan\left(\frac{2.8}{15.88+0.8}\right)
\approx \arctan(0.1679)
\approx 9.54^\circ
]

可以看到：

* 左右轮角确实不同
* 内侧轮更大
* 平均值接近 10°，但不严格等于等效角定义

# 23. 常见误区

## 误区1：左右前轮角应该一样

不对。理想无滑移转弯时必须不同。

## 误区2：阿克曼模型就是单轨模型

不完全对。
阿克曼是**真实左右轮几何关系**，单轨是它的**等效简化模型**。

## 误区3：(\delta=(\delta_l+\delta_r)/2) 是严格公式

不对。只是小轮距/大半径情况下的近似。

## 误区4：阿克曼模型适合所有速度

不对。它本质上是低速运动学模型。

# 24. 最后的高度概括

理想阿克曼转向模型的本质可以一句话概括：

> 在平面低速纯滚动条件下，为使四轮都无侧滑，左右前轮必须满足几何协调关系，使所有车轮对应同一个瞬时转动中心；进一步把左右轮等效成单前轮后，可得到车辆的标准运动学模型。

其最核心公式有三个：

[
\boxed{\tan \delta_l = \frac{L}{R-\frac{W}{2}}}
]

[
\boxed{\tan \delta_r = \frac{L}{R+\frac{W}{2}}}
]

[
\boxed{\dot{\psi} = \frac{v}{L}\tan\delta}
]

以及经典阿克曼约束：

[
\boxed{\cot\delta_r-\cot\delta_l=\frac{W}{L}}
]

---

想象车辆正在做一个匀速圆周运动：

转弯半径与轴距的关系： 在理想的阿克曼转向模型中，车辆所有车轮的轴线延长线交于一点，即瞬时旋转中心 (Instantaneous Center of Rotation, ICR)。

设转弯半径为 $R$（从旋转中心到车辆后轴中心的距离），轴距为 $L$，前轮转角为 $\delta$。根据简单的三角几何关系，我们可以构建一个直角三角形：

邻边：轴距 $L$
对边：转弯半径 $R$
角度：前轮转角 $\delta$
根据正切函数的定义： $$ \tan(\delta) = \frac{L}{R} $$

引入曲率： 曲率 $\kappa$ 定义为半径的倒数： $$ \kappa = \frac{1}{R} \implies R = \frac{1}{\kappa} $$

将 $R$ 代入上面的正切公式： $$ \tan(\delta) = L \cdot \kappa $$

求解转向角： 为了得到转向角 $\delta$，我们对等式两边取反正切（arctan）： $$ \delta = \arctan(L \cdot \kappa) $$
