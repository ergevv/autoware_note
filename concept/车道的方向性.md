在车道网（lanelet）数据结构中，"前向车道"和"后向车道"的定义基于**车道的方向性**：

## 前向车道 (Forward Lanelets)

**定义**: 从当前车道可以**直接行驶到达**的下一个车道

**获取方法**:
```cpp
const auto following_lanelets = routing_graph_ptr_->following(lanelet);
```

## 后向车道 (Backward Lanelets)

**定义**: 可以**流入**当前车道的上游车道，即车辆可以从这些车道驶入当前车道

**获取方法**:
```cpp
const auto candidate_lanelets = routing_graph_ptr_->previous(lanelet);
```

## 区别前后的方法

### 1. 拓扑关系
- **following** (前向): 当前车道 → 下一车道
- **previous** (后向): 上一车道 → 当前车道

### 2. 实际道路意义
- **前向车道**: 沿着交通流方向，车辆即将进入的车道
- **后向车道**: 沿着交通流反方向，车辆来自的上游车道

### 3. 在代码中的应用

#### 前向搜索 (forward search)
```cpp
lanelet::ConstLanelets RouteHandler::getLaneletSequenceAfter(
  const lanelet::ConstLanelet & lanelet, const double min_length) const
{
  // ... 
  const auto following_lanelets = routing_graph_ptr_->following(lanelet); // 前向车道
  // ...
}
```

#### 后向搜索 (backward search) 
```cpp
lanelet::ConstLanelets RouteHandler::getLaneletSequenceUpTo(
  const lanelet::ConstLanelet & lanelet, const double min_length) const
{
  // ...
  const auto candidate_lanelets = routing_graph_ptr_->previous(lanelet); // 后向车道
  // ...
}
```

### 4. 图解示意

```
[后向车道] --> [当前车道] --> [前向车道]
     ↑              ↑              ↑
   previous      current       following
   (后向)        (当前)        (前向)
```

### 5. 实际例子
如果一条道路是从西向东行驶：
- **前向车道**: 东边的车道（车辆行驶方向）
- **后向车道**: 西边的车道（车辆来向）

这种前后关系是根据车道的**几何方向**和**交通规则**确定的，不是绝对的地理方向。
