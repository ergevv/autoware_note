这些插件是 Autoware 行为路径规划器（Behavior Path Planner）中的**场景模块（Scene Modules）**，每个模块负责处理特定的驾驶场景。它们被组织成 4 个槽位（Slots），按优先级顺序执行。

## 1. 槽位架构说明

| 槽位 | 模块数量 | 执行优先级 | 设计意图 |
|------|----------|------------|----------|
| `slot1` | 1 个 | 最高 | 基础起步控制 |
| `slot2` | 7 个 | 高 | 常规行驶与变道避让 |
| `slot3` | 1 个 | 中 | 目标点泊车 |
| `slot4` | 1 个 | 低 | 动态障碍物处理 |

---

## 2. 各模块功能详解

### Slot1 - 起步规划

| 模块 | 功能说明 |
|------|----------|
| `start_planner` | **起步规划器**。负责车辆从静止状态（如停车场、红绿灯路口）安全起步的轨迹规划，检查周围障碍物并生成平滑的起步路径。 |

### Slot2 - 行驶与变道规划

| 模块 | 功能说明 |
|------|----------|
| `side_shift` | **横向移位**。执行小幅度的横向位置调整（如车道内居中、避开路肩），不涉及变道。 |
| `avoidance_by_lane_change` | **变道避让**。当同车道有障碍物时，通过变道到相邻车道进行避让。 |
| `static_obstacle_avoidance` | **静态障碍物避让**。处理静止障碍物（如停放车辆、施工区域），生成绕行路径。 |
| `lane_change_left` / `lane_change_right` | **自主变道**。根据全局路线规划，执行向左/向右的自主变道操作。 |
| `external_request_lane_change_left` / `external_request_lane_change_right` | **外部请求变道**。响应外部系统（如远程操作、交通管理）发起的变道请求。 |

### Slot3 - 目标点规划

| 模块 | 功能说明 |
|------|----------|
| `goal_planner` | **目标点规划器**。负责车辆到达目标点（如停车位、下车点）的末端规划，包括泊车入位、靠近目标点减速等。 |

### Slot4 - 动态障碍物处理

| 模块 | 功能说明 |
|------|----------|
| `dynamic_obstacle_avoidance` | **动态障碍物避让**。处理移动障碍物（如行人、其他车辆），生成实时避让轨迹。 |

## 3. 槽位设计逻辑

```
┌─────────────────────────────────────────────────────────────────┐
│                        规划执行流程                              │
├─────────────────────────────────────────────────────────────────┤
│  slot1  →  slot2  →  slot3  →  slot4                            │
│   ↓        ↓        ↓        ↓                                   │
│  起步     变道     泊车     动态避让                              │
│  (基础)   (常规)   (末端)   (补充)                               │
└─────────────────────────────────────────────────────────────────┘
```

### 设计原则

| 原则 | 说明 |
|------|------|
| **优先级递进** | 槽位编号越小，优先级越高。`slot1` 的模块优先于 `slot4` 执行 |
| **互斥分组** | 同一槽位内的模块可能存在互斥关系（如多个变道模块不能同时激活） |
| **状态传递** | 上游槽位的状态（如等待批准、失败）会传递给下游槽位 |
| **功能分离** | 将不同类型的规划场景分离到不同槽位，便于管理和调试 |

## 5. 典型场景执行流程

| 驾驶场景 | 激活模块 | 所在槽位 |
|----------|----------|----------|
| 车辆从停车场起步 | `start_planner` | slot1 |
| 车道内有静止车辆 | `static_obstacle_avoidance` | slot2 |
| 需要变更到左侧车道 | `lane_change_left` | slot2 |
| 到达目的地泊车 | `goal_planner` | slot3 |
| 前方有行人横穿 | `dynamic_obstacle_avoidance` | slot4 |
| 远程请求变道 | `external_request_lane_change_*` | slot2 |

---

## 总结

这套插件系统实现了**分层式行为规划架构**：
1. **slot1** 处理起步等基础场景
2. **slot2** 处理最常见的行驶和变道场景
3. **slot3** 处理目标点末端规划
4. **slot4** 作为补充处理动态障碍物

这种设计确保了规划系统的**模块化、可扩展性和安全性**，不同场景的规划逻辑相互独立又有序协作。
